# Tipografías

Autoalojadas para que la aplicación no dependa de un CDN de fuentes. Las carga
`css/app.css` con `@font-face`. Son el subconjunto `latin` (cubre el español)
en `woff2`, tomado de [Fontsource](https://fontsource.org).

| Familia | Uso | Licencia |
|---|---|---|
| STIX Two Text (variable, redonda y cursiva) | títulos y la gráfica | SIL OFL 1.1, `OFL-STIX-Two-Text.txt` |
| Fira Sans (400, 500, 600) | controles y texto | SIL OFL 1.1, `OFL-Fira-Sans.txt` |
